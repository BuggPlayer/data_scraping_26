IndiaMART Supplier Finder

Free, India-only wholesale/manufacturing supplier search by product keyword.

Different from the main scraper: IndiaMART searches by product keyword ("stainless steel wire", "cotton yarn"), not business type. It's India-only, always free (no API key, no quota), and doesn't return phone numbers — IndiaMART gates those behind a login. You'll get company name, the supplier's own website, city, rating, and review count; use the website with the email finder below for a contact.

Products only, not services: these pages only exist for physical products in IndiaMART's catalog — "wedding planner" or "marketing agency" will return 0 results because that page genuinely doesn't exist on their site (not a bug here). If a keyword returns nothing, browse indiamart.com yourself, find the real category, and paste its full URL instead — e.g. https://dir.indiamart.com/impcat/wicker-chair.html — any line here can be either a keyword or a full URL.
